### **Brief Introduction about the Project (Maximum 200 Words):**

> Traditional network security tools rely heavily on static signatures, leaving modern systems vulnerable to zero-day attacks and abnormal traffic surges like Port Scans and Denial-of-Service (DoS). While machine learning models offer superior anomaly detection, they are typically deployed as opaque "black boxes" that flag threats without explaining their underlying causes, making it hard for users to trust alerts or take decisive action.
>
> This project addresses these challenges by developing a real-time Network Intrusion Detection System (NIDS) powered by Explainable Machine Learning (XAI). The system captures live network traffic directly from the host adapter, aggregates packets into bi-directional flows, and extracts key statistical features. An optimized XGBoost classifier, trained on the benchmark CIC-IDS2017 dataset, provides rapid, high-accuracy threat classification with sub-millisecond response times.
>
> The core contribution of this work is explainability. Using TreeSHAP, the system translates complex model predictions into intuitive visual feature graphs and plain-English summaries, showing users the exact network metrics that triggered the detection. Paired with a real-time web dashboard, one-click Windows Firewall IP blocking, and an offline CSV upload feature for dataset benchmarking, the project delivers a transparent, practical security tool for everyday users.
